# Original overview refresh — November 12, 2026

## Scope and compatibility

This is the original `htekdev/gh-aw-overview` Astro/MDX guide, created March 26,
2026, with a pre-refresh repository baseline last pushed June 1. Its existing
navigation, dark styling, page wrappers, content collection, and Pages base path
remain in place. The update adds a Dynamic Workflows tab; it does not replace the
site, provision hosting, or change existing maintenance workflows.

## Changes in this refresh

- Replace stale headline preview/version/star-count badges with dated product
  status. GHAW is GA; the distinct Copilot Dynamic Workflows feature is preview.
- Correct universal PAT requirements: separate model inference authentication
  from GitHub API/write credentials and describe the current Actions-token path.
- Clarify compilation: frontmatter changes require regeneration of `.lock.yml`;
  the Markdown instruction body is loaded at runtime.
- Preserve the phased-delivery → DevOps → agent-assisted inner-loop → Continuous
  AI outer-loop teaching sequence, without inventing historical exclusions,
  productivity multipliers, or automatic authority to ship.
- Replace absolute containment claims with defense-in-depth and explicit trust
  boundaries. Distinguish GHAW output restrictions from repository reviews and
  Actions environment approvals.
- Replace the Home demo with one complete, manually triggered staged proposal;
  Get Started now follows that same source.
- Add the matching Dynamic Workflows page: extension orchestration, probabilistic
  reasoning, null/error paths, inherited grants, checkpoint semantics, soft credit
  ceilings, local-vs-cloud comparison, and a no-side-effect demonstration path.
- Preserve every original tab. Add active-page semantics, a scrollable mobile
  menu, Escape dismissal/focus return, and focused regression tests.

## Validation and safe demo boundaries

`examples/backlog-briefing.md` is outside `.github/workflows/` deliberately.
It is **not installed or active**. The Home component imports its exact text,
so displayed source cannot drift from the compiler-checked example.

Compiler validation:

```shell
gh aw compile --dir examples --no-emit --no-check-update
```

The refresh used the official checksum-verified v1.2.2 binary. Compilation
succeeded with zero warnings. This checks compiler syntax/configuration, not
inference entitlement, provider availability, prompt-injection immunity, or the
quality of future findings.

A hosted review is a separate gate: verify its result on the exact PR commit.
A local compile pass, an updated secret, or a completed-but-failed workflow
does not by itself establish successful runtime authentication.

Validate Copilot inference separately from GitHub API access: a successful
checkout or PR comment does not prove that the model-inference credential works.

Local test commands: `npm run test:coverage` and `npm run test:e2e`. Coverage
thresholds are 80% statements/functions/lines and 75% branches, scoped to the new
navigation JavaScript module. Content assertions check critical claims and
syntax-check the displayed Dynamic example without importing or executing it.
Astro templates/MDX are build-tested and browser-tested, not counted as JavaScript
coverage. Browser tests cover the changed tab flow on desktop and a 375px mobile
viewport, keyboard interactions, overflow, and automated WCAG 2.1 AA checks on
the new page. Automated checks are not a complete manual accessibility audit.

Observed results: **six source/content tests passed**, with **100% statements,
branches, functions, and lines for the navigation module**; **eight desktop/mobile
browser tests passed**; **15 static routes built**; the new tab's automated
WCAG 2.1 AA scans reported **zero violations** on both viewports. All **12 official
refresh source URLs** checked returned HTTP 200. No remote CI result is implied.
The accessibility checks exposed low-contrast footer text, color-only inline
links, and a nonfocusable scroll region; those were corrected rather than
excluded from the scan.

Video/screenshots and the HTML browser report are local test artifacts under
ignored `test-results/` and `playwright-report/`; no public upload is implied.
The existing production Pages pipeline is unchanged and deploys from `main`,
not this feature branch. There is no new PR-preview hosting.

No paid model run, Dynamic Workflow registration/run, GHAW dispatch, production
write, merge, or deployment was performed to demonstrate these examples.
The full historical gallery and every extended CLI example were not re-executed;
their prerequisites and current upstream help still need review before use.
No private event correspondence, attendee information, or internal work material
is included.
